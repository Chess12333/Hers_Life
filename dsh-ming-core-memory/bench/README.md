# bench —— 拿朴素 BM25 当下限，量我自己的检索

起因（2026-11-03 她给的）：灵枢 / memsearch / OpenViking / deja-vu / ReMe 五个记忆系统，
外加**朴素 BM25（自实现）当「零智能」的下限**。要的是「我这套到底比什么都不做多值多少」。

## 跑

```bash
node bench/run.mjs           # 出表
node bench/run.mjs --json    # 附带逐题排名
```

只读真记忆库（`~/.dsh/memory`）。三臂吃同一份语料、同一批题、同一套判据。

## 三臂

| 臂 | 是什么 |
|---|---|
| 朴素 BM25 | `bench/naive-bm25.mjs`：ASCII 词 + 中文 bigram，k1=1.5 b=0.75。无标题加权、无标签、无状态过滤、无关系层 |
| 溟（默认） | 真的 `memory_search` 工具实现（不是仿真）：标题×3、标签×2、正文按次数、idf 加权、覆盖度乘数、状态过滤、取代链、关联回捞 |
| 溟（含旧） | 同上 + `include_retired` |

## 判据（三条，都能数）

1. 正解在不在前 1 / 前 3 / 前 5 —— 只数主列表，不含「关联」和「另有…被取代」那两段
2. 现行口径题：输出里有没有把旧的那条标成旧的
3. 每题耗时 + 返回字数（成本代理；返回的字都要进上下文，等于钱）

## 题库

`bench/questions.mjs`，12 题，三类：

- **A 词面对得上**（5 题）：问法里就有原文的词，BM25 该赢或平
- **B 同义改写**（5 题）：问法避开原文关键词，看会不会零命中
- **C 现行口径**（2 题）：库里躺着旧的，看谁分得清新旧

题目是「我真会问的自家伙计」那种问法，不是造出来的评测语料。

## 已知局限（写在前面，免得数字被当成绩吹）

- 语料只有 75 条、题目 12 道，**n 太小**，任何两家的差距都不该外推。
- 语料是**我自己的库**，不是公共数据集——跟灵枢 `hive-memory-bench` 的六家同口径数字**不可比**，
  那边是小说/政论语料 × 184 题 × 生成器作答，这边是「能不能把自己写过的东西捞回来」。
- 只测检索，不测「拿去推理」——灵枢那份基准的结论一已经说了：推理是模型给的，记忆系统给的只有依据。
- 同义改写没做到「零共享 bigram」的极端版，所以 B 类没有真正压出关键词检索的上限。

## 2026-11-03 第一次跑出来的东西（留档）

修之前：

| 臂 | @1 | @3 | @5 | MRR | 中位耗时 |
|---|---|---|---|---|---|
| 朴素 BM25 | 11/12 | 12/12 | 12/12 | 0.958 | 0.2 ms |
| 溟（默认） | 7/12 | 7/12 | 7/12 | 0.583 | 19.3 ms |

原因不是「比 BM25 弱一点」，是**按空格切词**：一句人话问出去整句是一个 token，库里没有一句
含这句话的，于是零命中——只有敲关键词才灵。B 类 5 题全灭就是这么来的。

改成 ASCII 词 + 中文 bigram + idf + 覆盖度乘数之后：

| 臂 | @1 | @3 | @5 | MRR | 中位耗时 | 每题返回字数 |
|---|---|---|---|---|---|---|
| 朴素 BM25 | 11/12 | 12/12 | 12/12 | 0.958 | 0.2 ms | 450 |
| 溟（默认） | 11/12 | 12/12 | 12/12 | 0.958 | 13.5 ms | 2040 |
| 溟（含旧） | 10/12 | 12/12 | 12/12 | 0.917 | 13.8 ms | 1867 |

读法：**准确率追平，代价是 67 倍时间、4.5 倍返回字数。**多出来的字是取代链和关联块——
它们不帮忙排名，只帮忙「知道哪条是旧的、哪条跟它有关」。这件事 BM25 做不到，也是这边唯一的结构性优势。

两个坑（都在第二次跑之后才发现，记在这儿）：

1. 中文 bigram 会切出「么办」这种少见又没意义的碎片，光靠 idf 它反而最值钱——
   一句「web_search 报 401 怎么办」被讲「怎么读贴吧」的那条压住。加覆盖度乘数才压回去。
2. `String.match(/g)` 返回的是字符串不是 match 对象，写 `bump(m[0])` 只会拿到首字符：
   `web_search` 被切成了 `w`。分词看着像在工作，其实全是单字母。
