# 溟的网页取文（0.4.0）

改完在浏览器扩展管理页点一下**刷新**，再刷新要取文的网页。

## 两条入口

- **右键 →「溟：指一段」**：页面进入指认模式，光标指到哪块就高亮哪块，
  `[` `]` 收放、`Esc` 取消，**点一下**把这一块交给桌宠。
- **选中一段字 → 右键「交给溟：看这段」**（或 `Ctrl+Alt+S`）：兜底的老路。

交出去的是那一块的文字（最多 2 万字）、网址、标题；B 站另带 BV 号、UP 名、播放进度。
输入框、可编辑区、密码框一律不指。

## 0.4.0 改了什么（2026-11-17）

以前直接 POST 到桌宠 sidecar 的 `47322/webpick`——那里是「收到就覆盖 webpick.json」，
没配对、没请求身份、连续交两段会互相覆盖。现在改走桌宠插件自己的口：

```
http://127.0.0.1:51557/dsh-ming-mousepet/api/webpick/pick
```

- **带 token**（选项页填），不对就 401，不落盘
- **带 requestId**，按 id 落盘到 `live/webpick/`
- **忙就不覆盖**：上一段没被取走时回 409，扩展弹通知「上一段还没取走」，**不重试**
- 超长（2 万字 / 256KB）回 413

`47322` 那条老路还在（sidecar 没动），但默认不走它。要回退就在选项页把地址改回去。

## 第一次装

1. DSH 里桌宠插件在跑（日志会有 `浏览器取文：/dsh-ming-mousepet/api/webpick/*`）
2. `chrome://extensions` → 开发者模式 →「加载已解压的扩展程序」→ 选这个目录
3. 点扩展图标 → 选项页 → 粘贴 token → 保存 →「测一下连接」

token 在 `%USERPROFILE%\.dsh\ming-mousepet\webpick-token.json`（第一次运行桌宠自动生成）。

## 已知

- 一次只发一段：上一段没取走，下一段会被拒（这是故意的，防覆盖）。
- 页面没刷新时右键可能没反应——装完/刷新扩展后刷一下页面。
