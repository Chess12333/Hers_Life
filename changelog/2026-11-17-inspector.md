# 新增可选查看页：记忆来源、状态与替代关系

2026-11-17，待发布。

在 DSH 设置增加“记忆查看”：筛选已有归档笔记，查看来源类别、状态、日期、原文件、正文和替代/合并关系。未知来源明确显示未知，旧记录不当成当前结论。

从现有文件只读展示，已删除记录不展示，拒绝写请求。无模型调用、自动记录、后台轮询或新数据库；正文以纯文本显示。来源类别是已有文件的标注，不等于事实已经核实，也不承诺有原始聊天逐字证据。

## 使用

更新 core-memory、重启 DSH 并刷新网页后，在设置打开“记忆查看”。需要网页 slots/webServer；没有这些服务时原有记忆工具继续工作。详见 dsh-ming-core-memory/INSPECTOR.md。

## 验证

```
node dsh-ming-core-memory/qa-inspector.mjs
```

以上脚本已在独立于其他改动的分支通过，变动的 JavaScript 语法检查通过。使用合成资料；未在维护者实际 DSH/AstrBot/QQ 环境联调。

此项不改变群聊/私聊共享，不新增关于人的自动长期记忆或情绪判断。

界面代码沿用已经通过 React 18 + Edge 实际操作与 390 像素布局检查的版本；重新检查了本分支独立的文件/接口逻辑。网页宿主挂载仍需实际 DSH 确认。
