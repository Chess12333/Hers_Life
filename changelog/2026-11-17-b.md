# 修复 B：自动提醒不再被记成真人原话

2026-11-17，待发布。

浏览、兴趣、接续和定时插件生成的自动消息，原来可能以用户身份进入共享对话；自主浏览轮换会话也可能漏过过滤。现在只排除已知自动生产者及数字轮换浏览会话，保留 QQ/AstrBot 等桥接转交的真人消息。

旧共享缓存和 QQ 摘要出口采用同一排除规则；没有删除原始会话，也不猜测清理缺少来源的历史真人记录。群聊/私聊共享及日记、状态注入保持原样。

## 使用

更新 memory 插件后重启 DSH。普通真人消息仍应被正常记住，自动提醒不应被引用成用户说过的话。

## 验证

```
node dsh-ming-memory/qa-source.mjs
node dsh-ming-memory/qa-clean.mjs
node dsh-ming-memory/qa-share.mjs
```

以上脚本已在独立于其他改动的分支通过，变动的 JavaScript 语法检查通过。使用合成资料；未在维护者实际 DSH/AstrBot/QQ 环境联调。

此项不改变群聊/私聊共享，不新增关于人的自动长期记忆或情绪判断。
