# 新增可选插件：手动记录共同活动进度

2026-11-17，待发布。

新增独立可选插件 dsh-ming-activities，手动记录标题、链接、当前进度、下一步和进行/暂停/完成/不再继续状态。支持筛选、复制接续说明及确认删除。

保存到工作区 live/shared-activities.json；同实例串行写入与临时替换，版本冲突保留草稿，损坏文件保留并报错。只由一个 DSH 实例负责写入；不提供多进程协作锁。不抓聊天、不注入每轮提示、不调用模型或安排提醒。

## 使用

需按 dsh-ming-activities/README.md 单独安装并配置 MING_WORKSPACE 或 root，合并代码不会自动启用。AI 不会自动知道卡片变化，需要时复制说明到聊天。停用插件保留记录文件，删除卡片没有回收站。

## 验证

```
node dsh-ming-activities/qa-activities.mjs
```

以上脚本已在独立于其他改动的分支通过，变动的 JavaScript 语法检查通过。使用合成资料；未在维护者实际 DSH/AstrBot/QQ 环境联调。

此项不改变群聊/私聊共享，不新增关于人的自动长期记忆或情绪判断。

界面代码沿用已经通过 React 18 + Edge 实际操作与 390 像素布局检查的版本；重新检查了本分支独立的文件/接口逻辑。网页宿主挂载仍需实际 DSH 确认。
